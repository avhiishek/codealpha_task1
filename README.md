# Task 1 — Simple E-commerce Store

## Requirements
- Node.js 18 or newer
- npm

## Run
```bash
npm install
npm start
```

Open http://localhost:3001

The SQLite database is created automatically on first run. Register an account to use account-only features.

## Main features
- Product catalogue and detail view
- Registration and login
- Session-based shopping cart
- Order processing and order history
- SQLite persistence
